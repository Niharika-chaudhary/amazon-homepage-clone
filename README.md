# Amazon Homepage Clone

A simple recreation of Amazon's homepage built using HTML and CSS as part of my frontend web development learning journey.

## Features

* Navigation bar with a search bar
* Hero banner section
* Product category cards with images
* Footer section

## Technologies Used

* HTML5
* CSS3

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
